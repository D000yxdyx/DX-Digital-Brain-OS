# Security Policy

DX Digital Brain OS is an early prototype intended for local development and evaluation. It has not received a production security review and provides no production-environment security guarantee. Do not deploy it with sensitive data or expose it to untrusted networks.

## Reporting a vulnerability

If GitHub's Security tab offers private vulnerability reporting for this repository, use that channel and include only the details needed to reproduce the issue safely.

If private reporting is unavailable, do not publish credentials, exploit details, private logs, or sensitive personal data in a public issue. You may open a minimal public issue asking the repository owner to provide or enable a private reporting route, without including the vulnerability details.

There is no published response-time commitment, support SLA, or guaranteed remediation timeline. Please do not test against production, shared, or third-party systems.

## Supported status

No release is designated as production-supported. Treat the current code as experimental and review its configuration, dependencies, and limitations before local evaluation.
